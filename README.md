# Tessera Lumen

## Run the app

### Frontend
`ash
cd frontend
npm run dev
`\nOpens at http://localhost:5173

### Backend
`ash
cd backend
npm start
`\nRuns at http://localhost:4000

## Zoho CRM (optional)
Copy backend/.env.example to backend/.env and add your ZOHO_ACCESS_TOKEN.
The app works fully without it.
